# Abiotic-Factor-Hardcore-Death-Modifier
Hardcore-Light Death System

Encourage players to avoid dying and iteract with more of the gameplay systems,
but without being as penalizing.

- Anmesia Gate/Reduce Player skills after X number of deaths
- Extra Life System setting (extra_lives) is Configurable in config.lua
- If running hardcore, revive the player until extra lives run out.
- Set the reset_xp level in config.lua to control XP reset level (default level 3)
