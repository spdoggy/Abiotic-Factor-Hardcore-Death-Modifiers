# Abiotic-Factor-Hardcore-Death-Modifier
Hardcore-Light Death System

Encourage players to avoid dying and interact with more of the gameplay systems, 
but without being as penalizing as full on hard-core. Works with both non-hardcore and
hard-core game play settings. Allows Iron-Mode play without perma-death.

- Anmesia Gate/Reduce Player skills after X number of deaths
- Extra Life System setting (extra_lives) is configurable in config.lua
- Hardcore players can be set to be re-spawned automatically while extra lives greater than 0
- Hardcore can be further extended by setting no_hardcore_perma_death to always revive players
- Set the reset_xp level in config.lua to control XP reset level (default level 1)
